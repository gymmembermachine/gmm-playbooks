# Sell Serve Succeed Viral Giveaway Play Checklist (Internal Viral Giveaway Checklist 3.0)
Drive doc 1Q0dVHaz0RVuUbz_uVvIlXR9UxY6mkGay_r6OYWEcS38 (G.R., 2022-2023). NOTE: this is the INTERNAL (GMM ops team) setup checklist. "SSS" = Sell Serve Succeed = the old name for the GMM CRM (GoHighLevel). The client-facing play lives in Circle: https://gmm.circle.so/c/project-zero/sections/322147/lessons/1188632 (not scraped). Circle DFY calendar framing: "The viral giveaway play is a FANTASTIC option for those that want to build their list in that 4 to 10 day window right before Christmas." August lesson: "a viral giveaway that leads into your BTS program."
Joint venture notes doc (sample emails to local biz owners): 1Vl-5uRZqKbwZOn43umFKoTJvze-KEcXLYWd4CvslDLg

- Watch Overview Strategy Video: https://www.loom.com/share/4bdaa916ffb44bb68d30f75dad19d001
- Decide on Native Kingsumo.com or Wordpress plug-in method.
- If going native route, sign up for an account at kingsumo.com, then follow the Directions: https://www.loom.com/share/03ab44d7807643c9b71f6c4abf980feb
  - Set Up Giveaway
    - Add Title of Giveaway
    - Add Landing Page Body Copy from Swipe File: https://docs.google.com/document/d/14ORCMw8aSMMSL6OtkulO_hJ4XCn8F4C2pqtUfhDa5wY/edit
    - Add Dates/Times for Start Time and End Time
    - Adjust Giveaway Rules
    - Adjust Prize Information
    - Upload Background Image (Any large image you have!)
    - Complete integration to SSS via Zapier with Zap Template
      - Connect to your SSS account by copying API key (found in SSS under Settings > Company)
      - Tag all entries as "entered giveaway," which will populate them into the SSS Viral Giveaway Pipeline
      - If using the application step, give all entries an additional tag of "incomplete application," which will kick off the campaign to driving them to submit an application
      - Mark "Tag as Lead" as True
- If you have a Wordpress site, follow the Directions: https://www.loom.com/share/a4267466e3ba4995908b8ef3563cc69d
  - Download Kingsumo Plugin, install, paste SSS License Key from Swipe File, activate
  - Adjust Settings (ask for first names, input client location)
  - Set Up Giveaway [Add New]: title, landing page body copy from swipe file, dates/times, rules [remove IG, youtube, FB bonus entries unless otherwise noted], number of extra entries per referral, prize info, qualifying questions [remove/make inactive unless otherwise noted], background image, Zapier webhook, Zapier integration (same tags as above)
  - Preview page, publish, copy and save landing page address
  - Add Confirmation Email Copy from Swipe File
  - Delete KingSumo Announcement Email
  - Test Giveaway w/ sample contact
- Complete your application funnel in GMM (overview: https://www.loom.com/share/1edc6def71bf4ab1b2e93cb9ac280849)
  [application page] Add your logo; confirm application form (https://www.loom.com/share/fc9321d029df4c8aa1cdc2c278f39265); set page "go to next step" on submit; save
  [thank you page] Add your logo; add thank you message; save
  [publishing] Assign domain to funnel (https://www.loom.com/share/843e45ab296b4fc29b15734948853e84); add tracking pixels (FB for sure, GTM optional) (https://www.loom.com/share/0ef20b36335e43e89eba7145c452d517)
- Edit Custom Values in SSS under Settings > Custom Values (https://www.loom.com/share/7674c24d40fa4c45a0478921c1e223e9)
  - "viral_giveaway_prize_name_eg_6week_total_transformation_package" (name of your prize)
  - "viral_giveaway_prize_value_eg_800" (monetary value of your prize)
  - "viral_giveaway_link" (the King Sumo/Wordpress giveaway link)
  - "viral_giveaway_application_page" (link to your Viral Giveaway Application funnel)
- Edit Workflow Wait Times, and Emails (https://www.loom.com/share/4984635ac696408092fef4725f6131a1) (No edits necessary for the Viral Giveaway Drive to Application Workflow)
  - Workflow 1: Viral Giveaway Launch
    - Day Before Launch Email: edit start time of giveaway, number of winners
    - Wait 1: send next email at previously announced start time
    - Morning of Launch Email: number of winners, announcement date, add testimonial
    - Friday Night Swipe Email: number of winners
    - Wait 4 (after Friday Night Swipe): adjust to giveaway length so next email sends two days prior to deadline
    - 2 Days Out Email: add testimonials
    - Last Day Email: number of winners
    - Wait 6 (final): so next email sends 2 hours prior to deadline
    - Two Hours Left Email: number of winners, text in red for prize details
  - Workflow 2: Viral Giveaway Announcement
    - Day Before Winners Announced Email: announcement time
    - Wait 2: so Announcement Email sends at the time indicated
    - Announcement Email: links to orientation sign-ups for non-winners, number of winners, winner names, number of entries received
- Publish All Workflows
- Import Your Contact List and add all Contacts to Viral Giveaway Launch Workflow (https://www.loom.com/share/04ee90ddd9ad47eab0ea21a62c19c073)
- Edit and Schedule Social Media Posts
  - Promote to Internal Members' Group (sample post in Swipe File)
  - [Optional but Recommended]: Use the joint venture strategy and share with local biz owners (Directions and Sample Emails: https://docs.google.com/document/d/1Vl-5uRZqKbwZOn43umFKoTJvze-KEcXLYWd4CvslDLg/edit)
- Drive Your Follow-up Offers and Make $$$$!
